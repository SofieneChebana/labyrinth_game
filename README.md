Simple labyrinth game made in C using SDL (Simple DirectMedia Layer). <br>

<strong>The main purpose of this project is to help me improve my understanding of low‑level programming concepts in C. Implementing a simple labyrinth game with SDL provided a practical environment to experiment with memory management, rendering, and real‑time input handling. <br> <br> </strong>
